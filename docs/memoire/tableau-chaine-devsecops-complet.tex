\paragraph{Interpretation du statut.}
\begin{itemize}
  \item \textbf{TERMINE cote depot} : la brique technique est entièrement conçue, implémentée, versionnée et documentée dans le dépôt de code.
  \item \textbf{DEPENDANT\_DE\_L'ENVIRONNEMENT} : la brique est prête dans le dépôt, mais sa preuve d'exécution runtime finale dépend de la disponibilité d'une cible d'infrastructure (cluster kind, registre sécurisé, métriques actives, etc.).
  \item \textbf{PRET\_NON\_EXECUTE} : la trajectoire est planifiée et documentée avec des fichiers de configuration prêts à l'emploi, mais non activée en runtime local de démonstration.
  \item \textbf{PARTIEL} : le fonctionnement réel est partiellement observable dans la démonstration locale.
\end{itemize}
