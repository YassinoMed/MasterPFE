## 8. Procédure pour 100/100 opérationnel

```bash
# 1. Installer ArgoCD (10 min)
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/v2.14.0/manifests/install.yaml

# 2. Bootstrap — UNE SEULE commande
bash bootstrap-platform.sh

# 3. Tout est déployé automatiquement via ArgoCD App of Apps
# Falco, Harbor, Vault, Velero, cert-manager, Kyverno, PostgreSQL HA

# 4. Activer les composants souhaités
kubectl patch configmap securerag-feature-flags -n securerag-hub \
  --type merge -p '{"data":{"ENABLE_OPENTELEMETRY":"true"}}'

# 5. Valider
bash scripts/validate/validate-new-components.sh
```
